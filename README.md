# Desplazamiento de Feynman

Proyecto Python para estudiar el desplazamiento de Feynman.

## Desarrollo

Se recomienda crear y activar un entorno virtual antes de instalar el proyecto:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

El paquete fuente está en `src/desplazamiento_feynman/`.
